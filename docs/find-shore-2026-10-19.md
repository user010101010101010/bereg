# «Найти берег»: реализация и проверки

## Поведение

После завершения анкеты сразу открывается персональный план. Практика не имеет
отдельного маршрута, не открывается сама и не добавляется в список обязательных
задач. Одна карточка предложения находится в разделе эмоциональной поддержки:
при ответе «Очень тяжело» — после ближайшего действия, в остальных случаях —
после списка задач. Срочное действие по защите остаётся выше предложения.

«Продолжить без паузы» сворачивает карточку; кнопка повторного открытия остаётся.
Вручную практику также можно открыть из окна «Мне сейчас тяжело» и из инструкции
шага эмоциональной поддержки. Старое интерактивное упражнение в окне поддержки
заменено этой же практикой.

Используется существующее окно поддержки на Radix Dialog. Три инструкции идут
по нажатию кнопок; сцена SVG добавляет три камня, растения и дорожку. Назад не
убирает уже появившиеся элементы. Пропуск и закрытие завершают текущий сеанс.
При новом ручном запуске инструкции начинаются с первого шага.

После третьего действия доступен необязательный вопрос. Любой ответ, в том числе
«Стало некомфортно», не меняет прогресс задач. При дискомфорте анимации сцены
отключаются до конца сеанса. Нет автоматического повторения, звука, камеры,
ввода названий предметов, таймера или ожидания между шагами.

## Данные и аналитика

В существующий SavedCase добавлено необязательное поле `shorePractice`:
`shown`, `collapsed` или `completed`. Версия контейнера хранения остаётся v2.
Старые случаи читаются без нового поля; исходная резервная запись v1 сохраняется.
Свой статус есть у каждого собственного случая и случая близкого. В режиме без
сохранения статус живёт в памяти, как остальные данные случая. Практика до
создания случая сама по себе не создаёт сохранение.

Стадия упражнения, элементы сцены и самочувствие остаются в памяти компонента
сеанса. Они не входят в SavedCase, JSON-экспорт, параметры целей или dataLayer.
Новых аналитических событий не добавлено. Завершение не вызывает
`plan_step_done` и не отмечает шаг психологической помощи выполненным.

Содержимое окна и группа ответа имеют `ym-hide-content`; поля ответа —
`ym-disable-keys`. В существующем коде Метрики Вебвизор и карта кликов выключены.
Тесты исполняют и проверяют инициализацию счётчика, отсутствие новых вызовов
аналитики при практике и отсутствие самочувствия в сохраняемой записи.
Фактические сетевые запросы сторонних SDK и настройки кабинетов не наблюдались.

## Возврат и доступность

Окно сохраняет URL и позицию прокрутки при открытии. При закрытии восстанавливает
координаты, если пользователь не перешёл на другую страницу. Существующий
механизм возврата фокуса использует `preventScroll`. Из шага практика открывается
поверх инструкции и возвращает к её кнопке.

Инструкция получает фокус при переходе; её заголовок, номер и текст связаны ARIA.
Необязательный ответ — нативная группа радиокнопок с подписями. Закрытие через
Escape и ограничение фокуса остаются функциями существующего Radix Dialog.
Основной текст не меньше 16 px; на узком экране кнопки идут перед иллюстрацией.
Анимация короткая, без повторения, с `prefers-reduced-motion: reduce`.

## Результаты проверок

| Проверка | Результат |
| --- | --- |
| План сразу после анкеты, без автоматического окна | Пройден контроллерный тест реального приложения |
| Добровольный запуск, отказ и повторное ручное открытие | Пройден; статус отказа сохраняется после перезагрузки |
| Три шага, назад, пропуск, повторное открытие | Пройдены тесты реальных обработчиков компонента |
| SVG: три камня, растения, дорожка | Проверен отрендеренный HTML/SVG каждой стадии |
| Вопрос можно пропустить; все три ответа | Пройден; дискомфорт останавливает движение без повторного запуска |
| Прогресс и психологическая помощь | Не меняются после завершения практики |
| Ответы, черновики и свой/чужой случай | Пройдены проверки сохранения и изоляции |
| Ошибка записи и повторное сохранение | Старые данные остаются; повтор сохраняет актуальный выбор |
| Прежнее место | Проверен вызов восстановления координат; реальная прокрутка браузера не проверена |
| 320, 360, 390, 430, 768, 1440 px | Проверены медиаправила и размеры текста в реальном CSS; не браузерные измерения |
| Клавиатура и экранный диктор | Проверены разметка, подписи и обработчики; реальные Tab/Escape, VoiceOver/NVDA не проверены |
| Отключение движения | Проверены CSS для системной настройки и состояния дискомфорта |
| Приватность | Самочувствие не поступает в сохранение или наши аналитические вызовы; внешняя сеть не проверена |

## Недоступные проверки

В этой среде нет инструмента control-browser. Поэтому реальные скриншоты сайта,
визуальный прогон мобильного/десктопного интерфейса, Safari и физический телефон
не выполнены. Скриншоты не заменялись макетами или сгенерированными картинками.

Применён [навык Sites](skill://plugin_connector_1p_689987207de08191979cf68eca2941c6/sites/SKILL.md):
«If `$control-browser` is unavailable, skip browser QA: do not start a preview
server, install a browser, or improvise another browser-control path.»

Для ручной проверки: закончить тестовый опрос → открыть практику → пройти три
шага → выбрать любой ответ или сразу вернуться. Затем свернуть предложение,
перезагрузить страницу и открыть практику через поддержку. Повторить со случаем
близкого и с включённым уменьшением движения в настройках системы.

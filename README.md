# Берег

Полная версия интерфейса для GitHub Pages: опрос, персональный план, поддержка, материалы, проверка подозрительной ситуации, черновики и сохранённый случай.

Случай и черновики хранятся только в текущем браузере, без регистрации и серверной базы. Очистка данных сайта удалит сохранение. Данные не синхронизируются между устройствами. На общем устройстве удалите сохранение после работы. В репозиторий пользовательские данные не попадают.

## Публикация

1. Создайте репозиторий `bereg` в своём GitHub-аккаунте и загрузите содержимое этой папки в ветку `main`, включая `.github/workflows/pages.yml`.
2. Откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. После успешного workflow **Publish Bereg to GitHub Pages** сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/bereg/`.

Пути ресурсов относительные: подходят для репозитория с любым именем, главного пользовательского сайта и собственного домена. Экраны открываются через `?view=...`, поэтому перезагрузка страницы не требует серверных rewrite-правил.

## Разработка

Node.js 24, pnpm 11.25.0.

```sh
corepack enable
pnpm install --frozen-lockfile
pnpm dev
pnpm build
pnpm preview
```

Готовая сборка находится в `dist`. Её можно разместить на любом статическом хостинге. Для ручной публикации без сборки используйте содержимое папки `ready-to-publish` из архива: загрузите файлы в корень репозитория и выберите в Pages **Deploy from a branch → main → /(root)**.

## Отличие от версии с сервером

Интерфейс и сценарии сохранены. Вход через ChatGPT и облачная база заменены на сохранение в браузере по выбору владельца продукта. Существующие случаи из серверной базы автоматически не переносятся.

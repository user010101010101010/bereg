# Берег

Полная версия интерфейса для GitHub Pages: опрос, персональный план, поддержка, материалы, проверка подозрительной ситуации, черновики и сохранённый случай.

Случай и черновики хранятся только в текущем браузере, без регистрации и серверной базы. Очистка данных сайта удалит сохранение. Данные не синхронизируются между устройствами. На общем устройстве удалите сохранение после работы. В репозиторий пользовательские данные не попадают.

## Публикация

1. Создайте репозиторий `bereg` в своём GitHub-аккаунте и загрузите содержимое этой папки в ветку `main`, включая `.github/workflows/pages.yml`.
2. Откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. После успешного workflow **Publish Bereg to GitHub Pages** сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/bereg/`.

Пути ресурсов относительные: подходят для репозитория с любым именем, главного пользовательского сайта и собственного домена. Экраны открываются через `?view=...`, поэтому перезагрузка страницы не требует серверных rewrite-правил.

## Разработка

Node.js 24, pnpm 11.25.0.

```sh
corepack enable
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm build
pnpm preview
```

Готовая сборка находится в `dist`. Её можно разместить на любом статическом хостинге. Для публикации готовой сборки без Actions можно выбрать **Deploy from a branch → main → /docs**.

## Отличие от версии с сервером

Интерфейс и сценарии сохранены. Вход через ChatGPT и облачная база заменены на сохранение в браузере по выбору владельца продукта. Существующие случаи из серверной базы автоматически не переносятся.

## Текущие возможности MVP

- Центрированный hero и композиция карточек по визуальному референсу; сохранены цвета, шрифты, волны и иконки «Берега».
- Нейтральная точка входа «Разобраться в ситуации».
- Ответы сохраняются во время опроса, включая текущий этап. «Мой случай» позволяет продолжить незаконченный опрос или готовый план.
- Отметки шагов, редактирование черновиков и заметки звонка в банк сохраняются автоматически. Ключ хранения прежний, старые случаи поддерживаются.
- Карточки чек-листа показывают инструкцию и критерий выполнения. Чекбоксы есть и в карточке, и в центральном окне подробностей.
- Банковский шаг: выбор из пяти банков, официальные телефоны и ссылки (проверено 17.10.2026), сценарий звонка с учётом согласия на операцию, вопросы сотруднику и заметки.
- PDF создаётся на устройстве: общий чек-лист, подробности оставшихся шагов, контакты и памятка звонка, активные ссылки, встроенный кириллический Onest. Данные не передаются стороннему сервису конвертации.
- Отметка шага фиксирует действие пользователя и не означает возврата денег или завершения рассмотрения обращения.
- Автоматические проверки покрывают миграцию, сохранение и снятие отметок, возобновление опроса, устойчивый ID случая, заметки и различия скриптов звонка.

`public/fonts/Onest-PDF.ttf` — статическое начертание Regular из исходного Onest, распространяется на условиях приложенной OFL. Готовый сайт также находится в `docs`.
